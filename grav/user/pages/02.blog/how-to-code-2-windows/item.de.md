## Was ist Git?

**Git** ist ein Kontrollsystem (VCS = Version Controlling System), mit dem Sie die Struktur von Dateien und Projekten (Projekt oder Repository) verwalten, zusammenarbeiten und ändern können. Es wurde 2005 von Linus Torvalds entwickelt, nachdem die Linux-Kernel-Entwicklung dem BitKeeper-Versionskontrollsystem die Lizenz entzogen hatte.

**Git** ist der De-facto-Versionskontrollstandard für die Softwareentwicklung und wird von vielen Open-Source-Projekten verwendet, darunter Linux, Android und Eclipse. Es bietet viele Vorteile, darunter:

* **Verteilte Architektur:** Jeder Entwickler verfügt über eine persönliche Kopie des Projekts (Arbeitskopie), die mit dem zentralen Repository synchronisiert werden kann.
* **Flexibilität:** Mit Git können Sie an mehreren Versionen eines Projekts gleichzeitig arbeiten und Änderungen dokumentieren.
* **Sicherheit:** Git verwendet kryptografische Hashes, um die Integrität und Authentizität von Commits sicherzustellen. Es verhindert, dass Daten manipuliert werden und verloren gehen.
* **Skalierbarkeit:** Git kann große Projekte effizient verwalten und ist auch für große Entwicklungsteams geeignet.

Git bietet eine Vielzahl von Befehlen und Funktionen, darunter:
* Commits: Aufzeichnungen über am Projekt vorgenommene Änderungen
* Zweige: Parallele Versionen eines Projekts, die für verschiedene Zwecke verwendet werden können.
* Pull- oder Merge-Anforderung: Ein Ansatz zur Überprüfung von Änderungen, bevor sie in das Haupt-Repository übernommen werden.
* Remote-Repositorys: Zentralisierte Speicherorte zum Speichern von Projektdaten, die Entwickler verwenden können.

Einige der am häufigsten verwendeten Git-Frontends oder Entwicklungshelfer[GitHub](https://github.com/), [Bitbucket](https://bitbucket.org/product/), [Gitlab](https://about.gitlab.com/), [Visual Studio Team Services](https://azure.microsoft.com/de-de/updates/visual-studio-team-services-azure-devops-projects/), Visual Studio Code (VSCode), [Eclipse](https://www.eclipse.org/downloads/), [Intellij Idea](https://www.jetbrains.com/de-de/idea/)Es lässt sich in viele Entwicklungsumgebungen und Tools integrieren und vereinfacht die Verwaltung und Zusammenarbeit. Was ist GitHub?
![git-github](git-github.png "git-github")
GitHub ist ein Produkt, mit dem Sie Ihre Git-Projekte auf einem Remote-Server (oder in der Cloud) hosten können.
![GitHub_Logo](GitHub_Logo.png "GitHub_Logo")

Es ist wichtig, sich daran zu erinnern, dass GitHub nicht Git ist. GitHub ist lediglich ein Hosting-Dienst. Es gibt andere Unternehmen, die Hosting-Dienste anbieten, die das Gleiche tun wie GitHub, wie zum Beispiel Bitbucket, Gitea und GitLab.
![github-mark](github-mark.png "github-mark")
