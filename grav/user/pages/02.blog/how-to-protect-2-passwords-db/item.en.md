Good day! Let's expand a little on the topic I started yesterday. In other words, let's try to explain easily with pictures how to create an encrypted carrier that can be carried everywhere. I am in it[VeraCrypt](https://www.veracrypt.fr/en/Home.html)It uses a ***free*** program.

===

### How to install and start using immediately?
1. Download the installer according to your system
2. Start the installation and accept the License
3. Select the installation folder
4. Installation
5. Start on Windows 11
6. Choose where to attach
7. Create an empty file without extension anywhere you like
8. Select and create an encrypted folder to store the created files
9. Choose encryption type and folder size
10. Enter the password in the encrypted folder
11. Create encryption as a random option with mouse movement
12. Complete creation of encrypted folder
13. Attach the created folder encryption to the reporting system
14. Put your password database in your encrypted folder
15. Learn to remove and close your encrypted folder when you're done using it!

### Conclusion

The portable version of VeraCrypt can now be taken anywhere by copying the encrypted folder to a USB-Stick. In doing so, we've also introduced another important application that can be used on multiple systems, like KeePassXC. Your data may not be private or important to you, but consider simple safeguards like these for your family, work, and community, and it's a big step in the public interest.
Well, anyway, we now have 50% protection against common hackers and data thieves. The other 50% can be done by keeping your system up-to-date and with an Anti-Virus program.
