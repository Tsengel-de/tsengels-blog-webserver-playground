Lassen Sie uns nun erklären, warum ich diese Liste erstellt habe.

##### 1. Mit welcher Linux-Version soll ich beginnen? (Welche Linux-Distribution soll ich für Anfänger starten)

Ich persönlich verwende Ubuntu ([Ubuntu](https://ubuntu.com/))verwendet Debian bei der Arbeit ([Debian](https://www.debian.org/))Es ist einfach zu bedienen. Außerdem, weil Ubuntu meiner Meinung nach eine einfache Anleitung für Anfänger und jede Menge Tutorials im Internet hat.

##### 2. Was ist ein virtuelles System? Wie benutzt man Linux so? (So ​​starten Sie mit virtualisiertem Linux)

Installieren und verwenden Sie das Programm mithilfe des Systems auf Ihrem System.
Dies sind die ersten Apps, die Sie ausprobieren sollten
- Virtualbox [https://www.virtualbox.org/](https://www.virtualbox.org/)
	- [Убунтуг хэрхэн Виндовс дээр Virtualbox-той суулгах вэ?](https://www.lifewire.com/install-ubuntu-linux-windows-10-steps-2202108)
- VMWare Workstation Pro [https://www.vmware.com/products/workstation-player.html](https://www.vmware.com/products/workstation-player.html)
	- [Убунтуг хэрхэн Виндовс дээр VMWare-тай суулгах вэ?](https://ubuntu.tutorials24x7.com/blog/how-to-install-ubuntu-on-windows-using-vmware-workstation-player)

Es wurde in vielen Anwendungen verwendet. Im Detail können Sie viele virtuelle Systeme erstellen und auf unterschiedliche Weise spielen. Virtualbox ist möglicherweise kostenlos, VMWare Pro Workstation möglicherweise teuer und Player möglicherweise kostenlos. Prüfen Sie Ihre eigenen Bedürfnisse.

##### 4. Wie installiere ich Ubuntu auf aktuellen Systemen? (So ​​installieren Sie Ubuntu im Multiboot/Dualboot)

Wenn Sie daran interessiert sind, Ihr Windows vor Problemen zu bewahren, ist es besser, eine Parallelinstallation durchzuführen.

[https://itsfoss.com/install-ubuntu-1404-dual-boot-mode-windows-8-81-uefi/](https://itsfoss.com/install-ubuntu-1404-dual-boot-mode-windows-8-81-uefi/)

##### 5. Wie installiere ich Ubuntu mit verschlüsselten Systemen? (So ​​installieren Sie verschlüsseltes Multiboot/Dualboot)

Es ist besser, Ihr gesamtes System zu verschlüsseln, insbesondere auf einem Laptop, da Sie es regelmäßig verwenden, nachdem Sie es unter Linux verwendet haben.

[https://www.mikekasberg.com/blog/2020/04/08/dual-boot-ubuntu-and-windows-with-encryption.html](https://www.mikekasberg.com/blog/2020/04/08/dual-boot-ubuntu-and-windows-with-encryption.html)

Wenn Sie unter Windows etwas tun, haben Sie immer wieder das gleiche Problem. Mir ist einfach langweilig, deshalb nutze ich auf meinem Gaming-PC nur Windows 11. Nun, man kann es auch verwenden, um Kinder oder Menschen zu unterrichten, 🤣🤣.
