I recommend using the following method to make it faster:
1. Learn to use the program by comparing it with the picture above
2. Make a list of all Mongolian Cyrillic letters in Unicode
3. Select and open the settings of the keyboard of the country you are using (mostly English and German, but if there are people from other countries)
4. Insert/replace Mongolian Cyrillic letters in Unicode in your favorite position from the above list
5. After doing a few tests, you are satisfied[суулгацыг нь хийгээд суулгаж ашиглах](https://blog.tsengel.de/mn/blog/mongolian-keyboard-layout-on-windows)
6. Voilà

#### Summary

If I can't type quickly on my computer, I feel like I'm wasting a lot of time,🤔. Unfortunately, especially for children who are just starting to learn, and then when they start learning a foreign language, they will also have to spell, 😭!

But the configuration I made is certainly not the best, because I made it for myself, i.e. I tried to insert Mongolian Cyrillic letters after letters with similar Latin words (people who write in English and German may understand it quickly),😁.

If you look at this Mongolian Cyrillic standard configuration, you can see that the expansion keys are simply not used (judging by the location used, it must have been copied from a mid-20th century typewriter). Why, 🤔? Well, well, never mind, now you've learned how to modify it yourself, share it with others. Or improve it and tell me.
