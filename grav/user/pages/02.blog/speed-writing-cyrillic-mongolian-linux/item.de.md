Dieses Mal werde ich in mongolischer Kyrillisch darüber schreiben, wie ich es unter Linux oder Ubuntu (andere Linux-Versionen sind normalerweise gleich, ich persönlich verwende Debian und Ubuntu 2) auf der Tastatur verwende. Jetzt wissen Sie, wie man auf Twitter viele chaotische Dinge schreibt. Wenn Sie sich gut vorbereiten, ist das ganz einfach 😅😂.

Es ist schön, dass mongolisches Kyrillisch auf allen mongolisch-fähigen Geräten ausgewählt werden kann, aber ich weiß immer noch nicht, wer es erstellt hat, und ich verstehe immer noch nicht, wie die Buchstaben angeordnet waren. Nachdem ich es ausprobiert hatte, änderte ich es sofort, um es an meine Bedürfnisse anzupassen. Eine einfache Vermutung ist, dass die kyrillische Schreibmaschine direkt kopiert wurde, 😜.

Haben Sie sich jemals gefragt: „Warum kann A nicht A drücken, B nicht B und U nicht U?“ 🤗🤓. Jetzt sehen Sie hier, wie es gemacht wird.

Zunächst sollte im System die mongolische Sprache ausgewählt werden. Und das habe ich getan[Кирилл үсгийн гарын суулгац](https://github.com/bachka/mongolian-keyboard-layout-linux)-ыгkann hier heruntergeladen und installiert werden. Der gesamte Code ist lesbar und lesbar, ohne die Position der Buchstaben zu verändern!

Sie können das Paket direkt herunterladen, extrahieren und installieren. Installieren Sie Git auf Ihrem System wie Esgool Pro et al

```
git clone https://github.com/bachka/mongolian-keyboard-layout-linux.git
``` 

**mn-custom**-Datei hat den Hauptgrund. Dort können Sie Ihre Briefe auch ganz nach Ihren Wünschen platzieren.
