In today's world, it is imperative that we protect ourselves and others by using a personal or corporate password database with many different types of data, such as choosing which one to take.


===

!!! This is the first step...

In today's article, I'll explain how to create and use a password database for yourself and your business. At work[Keepass](https://keepass.info/)used. But I personally[KeePassXC](https://keepassxc.org/)-гused because it is constantly updated and can be used on many systems. Also, the created database can be opened and used in 2 ways, that is, the format used is the same. Both of these apps are free and cannot be easily hacked, so remember your fund password well. And below is a picture of how to install and use KeePassXC.
