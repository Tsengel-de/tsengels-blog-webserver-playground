Жаахан бодлоо, та бүхэн угаасаа намайг IT энэ тэр гээд ойлгочихсон байгаа, зөв, 😌. Миний одоо 7-8 жил эрхлэж байгаа ажил мэргэжил (20 жил зүэр л байсан Хобби),😉😌. Харин анхан шатны эсвэл зүэр сонирхсон хүмүүст ямар нийтлэл оруулах вэ гээд бодоод олсонгүй гэвэл шал худал болно. 

===

Тиймээс сая зүэр толгойд орсон оо, дараагийн хэдэн цуврал нийтлэл болгон оруулахаар шийдлээ ... Яаг үнэндээ юу гэж бодсон бэ гэхээр байна штээ тээ, ингэж бодлоо:
> ***Намайг анх энэ сэдвээр эхлэж байхад ямар сэдвүүд байсан бол би илүү их цаг хэмнэх байсан бэ гэдэг асуудал, *** 🧐

***Эхний хэдэн сэдэв нь энэ :***
- Компьютерийн архитектур ба өгөгдлийн үндэстэй танилцах
- Програмчлалын хэл хэрхэн ажилладаг
- Интернет хэрхэн ажилладаг
- Тушаалын шугамын зарим үндсэн дүрмийг хэрэгжүүлэх
- Vim ашиглан текст засварлах ур чадвараа дээшлүүлэх
- Зарим HTML код
- Зарим CSS код
- JavaScript ашиглан програмчлаж эхлэх
- Python программаар үргэлжлүүлэх
- Java -ийн талаархи мэдлэгээ дээшлүүлэх
- Git ашиглан кодоо хянах
- Өгөгдлийн сан болон SQL ашиглан өгөгдлийг хадгалах
- Web Frameworks болон MVC -тэй танилцах
- Багцын менежерүүдтэй тоглох 
- Юю гм. олон асуудал биш асуудал байна ... Ө.х. хэн нэгэн сонирхолтой асуулт асуувал сэдэв шууд өөрчлөгдөнө. Үр бүтээлтэй байх гэдэг чухал шт, тэхдээ би өөрөө л тэрнийг ойлгоно, таных бас ондоо байхаа,😇. Аан тийм, дэс дараалал бол хийсвэр шөө, би цаг зав болон юу бичих сонирхол төрж таны болон миний цаг хэмнэж байгаагаас гээш, 🤗.

Таньд тоо хэрэгтэй гэж үү, харин ээ, 😝. Та сайн тоо боддог бол Логик сэтгэлгээ тань сайн болсон гэж найдна. Ондоогоор бол та миний хэлсэнээр хийгээд нухвал бас тодорхой хэмжээнд сайжрах магадлал байна. Эрдэм шинжилгээний асуудал хариуцсан хүмүүс бас ондоо хийх, ярих юм байгаа байх. Би танд харин аль² нь байж болохыг харуулж магад.

Өөрөөр хэлбэл танд би зөвхөн мэргэжил эзэмшихээс эхлээд яаж академийн зэрэглэлтэй эн зэрэгцэн бардам амьдарч болох талаар харуулна, мартчихгүй бол, хаха. Аль²-г үзчихсэн ч гэх юм уу, эргэлзээд ч байгаа юм уу, ажилсаг тэвчээртэй нь ялж болох нөхцөл, нүх сэв байдаг. Та харин ядаж сонсож, сонирхож сурсан бол би таньд туслая ...

!! Анхаар! Асуулт байхгүй байна гэдэг нь надад бол мэдэхгүй байна л гэж ойлгогдоно, уушлаарай,😅😂🤣.

Миний хэлсэнд сөрж та шантарч байгаа бол та угаасаа энэ сэдвээр эхлээд хэрэггүй биз дээ,😎.
