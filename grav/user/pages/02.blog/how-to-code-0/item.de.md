Mein Beruf, den ich nun seit 7-8 Jahren ausübe (Hobby seit 20 Jahren),😉😌. Wenn Sie jedoch darüber nachdenken, welche Art von Artikel Sie für Anfänger oder Interessierte veröffentlichen sollten, wäre dies völlig falsch.

===

Deshalb kam es mir in den Sinn und ich beschloss, es in die nächste Artikelserie aufzunehmen ... Ich möchte wissen, was ich wirklich gedacht habe, ich dachte so:
> ***Ich frage mich, bei welchen Themen ich mehr Zeit gespart hätte, als ich mit diesem Thread angefangen habe, *** 🧐

***Die ersten paar Themen sind:***
- Vertrautheit mit Computerarchitektur und Datengrundlagen
- Wie Programmiersprachen funktionieren
- Wie das Internet funktioniert
- Implementieren Sie einige grundlegende Befehlszeilenregeln
- Verbessern Sie Ihre Textbearbeitungsfähigkeiten mit Vim
- Ich suche HTML-Code
- Etwas CSS-Code
- Beginnen Sie mit der Programmierung mit JavaScript
- Fahren Sie mit Python fort
- Verbessern Sie Ihre Java-Kenntnisse
- Verfolgen Sie Ihren Code mit Git
- Speichern Sie Daten mithilfe von Datenbanken und SQL
- Vertrautheit mit Web Frameworks und MVC
- Spielen Sie mit Paketmanagern
- So etwas in der Art. Es gibt nicht viele Probleme ... O.h. Wenn jemand eine interessante Frage stellt, wechselt das Thema sofort. Es ist wichtig, produktiv zu sein, aber das verstehe ich selbst und Sie auch, 😇. Oh ja, die Reihenfolge ist eine Illusion, ich spare deine und meine Zeit, indem ich mich dafür interessiere, was ich schreiben soll, 🤗.

Brauchen Sie Zahlen, ja, 😝. Wenn Sie gut mit Zahlen umgehen können, ist Ihr logisches Denken hoffentlich gut. Wenn Sie an diesem Punkt tun, was ich sage, und es massieren, besteht eine gute Chance, dass Sie eine gewisse Verbesserung erzielen. Die Verantwortlichen für akademische Angelegenheiten haben dieses Jahr wahrscheinlich etwas zu tun und zu besprechen. Ich kann Ihnen zeigen, welches es sein kann.

Mit anderen Worten, ich zeige dir, wie du stolz neben deinem akademischen Abschluss leben kannst, angefangen beim einfachen Abschluss, haha. Unabhängig davon, ob Sie Al² gesehen haben oder Zweifel haben, gibt es Bedingungen und Fallstricke, die mit harter Arbeit und Geduld überwunden werden können. Aber wenn Sie zumindest lernen, zuzuhören und interessiert zu sein, werde ich Ihnen helfen ...

!! Aufmerksamkeit! Das Fehlen von Fragen bedeutet, dass ich es nicht weiß, sorry, 😅😂🤣.

Wenn Sie von dem, was ich gesagt habe, entmutigt sind, sollten Sie dieses Thema nicht beginnen, oder?
